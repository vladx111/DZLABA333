# Домашнее задание к работе 3

## Условие задачи

11. Написать и отладить программу расчета длины волны при
заданной частоте сигнала (от 50 до 200 ГГц – возможный диапазон
значений).

### Алгоритм

1. Начало
2. Объявить константу:
   - `C` = 29979245800  (см/с) — скорость света.
3. Задать исходные данные:
   - `f` — частота сигнала в ГГц .
4. Ввести частоту `f`.
5. Вычислить частоту в герцах:
   - `f_hz = f * 1 000 000 000`
6. Вычислить длину волны:
   - `lamda = C / f_hz`
7. Вывести результат расчёта с подстановкой значений в текст.
8. Конец
 ## Реализация программы
 #include <stdio.h>
#include <locale.h>

#define C  29979245800 

int main()
{
    setlocale(LC_CTYPE, "RUS");

    float f;
    float lamda;

    printf("Введите частоту сигнала (50–200 ГГц): ");
    scanf_s("%f", &f);
    if (f < 50 || f > 200)
    {
       printf("Выход за пределы частоты");
       
       return 0;
    }

    lamda = C / (f * 1 000 000 000);

    printf("Длина волны при частоте %.2f ГГц = %.2f см\n", f, lamda);

    return 0;
}  
## Результат работы программы  
Введите частоту сигнала (рекомендуемый диапазон: 50–200 ГГц): 100
Длина волны при частоте 100.00 ГГц = 0.30 см
